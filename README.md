# Na Nota
Na Nota é uma aplicação web interativa que ajuda você a treinar e evoluir na música de forma divertida. O jogo exibe uma nota na tela, capta o som do seu instrumento em tempo real pelo microfone do celular e valida se você acertou a frequência exata. Ideal para praticar percepção musical e afinação no seu próprio ritmo!

Ideia inicial do jogo é lidar com notas do violino
